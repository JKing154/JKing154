2025 and 2026 competition steering wheels

style="height:250px;">

Three-point bend test setup

Designed and fabricated the 2026 Cornell Racing steering wheel through multiple driver-tested iterations. The goal was to cut weight from the previous year while keeping the wheel strong enough to handle real race loads and improving how it actually feels to drive with.

To validate the panel material, I ran three-point bend tests across four different carbon fiber sandwich layup configurations. All four panels cleared the 700N structural threshold, so I selected the lightest one that still passed. The final wheel came in 30% lighter than the prior year with a 32 N/g strength-to-weight ratio.

Finished HertzTrap device

style="height:250px;">

MAE 2250 design poster

Built for Cornell's MAE 2250 Mechanical Design course, HertzTrap is a bug zapper designed specifically to target spotted lanternflies. A USDA study identified that spotted lanternflies are attracted to 60 Hz light frequency, so we used that as the lure mechanism, drawing them toward an electrified mesh that kills on contact.

The project covered the full design cycle from concept through fabrication and a final class presentation. It won People's Choice out of the entire class, voted on by peers and faculty.

style="height:250px;">

Assembled pocket AI assistant

Built a pocket-sized AI voice assistant using a Raspberry Pi Zero 2W, a Whisplay audio HAT, and a PiSugar 3 battery so it runs fully untethered. The goal was a device that works without any subscription or cloud dependency — everything either runs locally on the Pi or hits a free API tier.

Speech recognition uses faster-whisper running locally (tiny model to stay within the Pi Zero's limited RAM), the language model runs through Groq's API for speed, and text-to-speech uses Piper locally. The main remaining challenge is response latency — getting the full pipeline fast enough to feel natural to talk to.

Work in progress

Working on my 335i is less about following a guide and more about figuring out what's actually wrong before touching anything. The N55 is a well documented engine but it still throws problems that need real diagnosis — scanning codes, looking at live data, and understanding what the symptom is actually pointing to before ordering parts.

So far I have replaced the charge pipe (a known weak point on the N55 that cracks under boost pressure), swapped the rear lights, and done electrical troubleshooting. The car is an ongoing project and each fix teaches me something about how systems interact that you just don't get from a classroom.
